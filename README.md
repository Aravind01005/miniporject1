# Northstar Student Portal

A responsive React demo for a college student portal. It includes a demo sign-in screen and a dashboard with sample courses, attendance, grades, credits, class schedule, and recent activity.

## Run locally

```sh
npm install
npm run dev
```

## Demo sign-in

- Username: `student`
- Password: `campus123`

The sign-in is a client-side mock only. It does not authenticate against a server or store student data.
